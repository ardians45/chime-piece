## 🌟 Overview
**chime-piece** is an interactive, responsive Web 2.0 educational platform and academic e-portfolio designed to bridge abstract physics and STEM concepts with real-time collaborative digital inquiry.

### 🎯 Key Highlights:
1. **Interactive Physics Sandbox (HTML5 Canvas):** Real-time interactive physics widget in the hero section demonstrating Hooke's Law spring elasticity, atomic orbits, and inertia.
2. **5 Evaluated Web 2.0 Tools (Rubric Level 4):**
   - **Nearpod** — Synchronous slide synchronization, live "Draw It" force diagram canvas, and formative intervention.
   - **Socrative** — Real-time diagnostic Student Response System (SRS) and gamified Space Race.
   - **Moodle** — Modular science LMS, LaTeX-enabled quizzes, and rubric-based PDF grading.
   - **Pivot Interactives** — High-speed Direct Measurement Video (DMV) with calibrated digital tools.
   - **PhET Interactive Simulations** — Exploratory inquiry micro-worlds and Ohm's / Faraday's law modeling.
3. **Pedagogical Alignment:** Formally structured under the **SAMR Model** and **Bybee's 5E Instructional Model**.
4. **Author E-Portfolio:** Comprehensive profile, academic record from Universiti Teknologi MARA (UiTM), DOSM data analysis credentials, and downloadable CV.
