## 🌟 Overview
**chime-piece** is an interactive, responsive Web 2.0 educational platform and academic e-portfolio designed to bridge abstract physics and STEM concepts with real-time collaborative digital inquiry.

### 🎯 Key Highlights:
1. **Interactive Physics Sandbox (HTML5 Canvas):** Real-time interactive physics widget in the hero section demonstrating Hooke's Law spring elasticity, atomic orbits, and inertia.
2. **5 Evaluated Web 2.0 Tools (Rubric Level 4):**
   - **Nearpod** — Synchronous slide synchronization, live "Draw It" force diagram canvas, step-by-step visual infographics, and recorded video walkthrough (`https://youtu.be/nrTvHsxwYn0`).
   - **Socrative** — Real-time diagnostic Student Response System (SRS), gamified Space Race, and 3-step visual tutorial infographics.
   - **Moodle** — Modular science LMS with MoodleCloud (`https://moodle.com/cloud/`), formatted formula quizzes, and 3-step visual tutorial infographics.
   - **Pivot Interactives** — High-speed Direct Measurement Video (DMV) with calibrated digital tools and 3-step visual tutorial infographics.
   - **PhET Interactive Simulations** — Exploratory inquiry micro-worlds, step-by-step visual infographics, and recorded video walkthrough (`https://youtu.be/DfA0-d09Vpc`).
3. **Tutorial Media Integration:** Includes 13 high-resolution step-by-step visual infographic guides with a built-in zoom lightbox viewer and embedded YouTube video walkthroughs.
4. **Pedagogical Alignment:** Formally structured under the **SAMR Model** and **Bybee's 5E Instructional Model**.
5. **Author E-Portfolio:** Real portrait of Adriana Alya Binti Jefri, academic record from Universiti Teknologi MARA (UiTM Kampus Puncak Alam & Kampus Tapah), Department of Statistics Malaysia (DOSM) data analysis credentials, and pedagogical philosophy.
